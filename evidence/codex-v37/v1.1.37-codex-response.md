## 3. 기기 없는 실제 앱 transport 재현

`scripts/verify-review-trpc-client.mjs`는 앱의 `lib/trpc.ts`와 같은 `@trpc/client`의 **`httpLink` + `superjson`** 구성으로 새 preview에 요청했다. 브라우저 fetch 형식/로컬 handler direct call이 아니라 tRPC client의 query/mutation 및 `TRPCClientError` 파싱을 사용했다.

| 항목 | 결과 |
|---|---|
| 명시적 승인 범위 | `review-tech` / `review-only`, `review-tech-2` / `review-only-2` 합성 계정만 사용 |
| 대상 origin | `https://futureenergytech-4tlv7asl8-futureenergytech.vercel.app` |
| 운영 고객·운영 DB·실제 SMS | 요청·저장·발송하지 않음; response의 SMS 상태는 `smsSubstituted` 합성 값만 사용 |
| 미인증 가격 query | `401`, `UNAUTHORIZED`, JSON-RPC `-32001`, path `prices.listActive` |
| 본인 일정 | 기사 `910001`은 합성 request `810001`만 조회 |
| 동의 전 출발 | `412`, `PRECONDITION_FAILED`, JSON-RPC `-32012`, path `location.startTracking` |
| 인증 동의 저장 후 출발 | `hasConsented: true`, `synthetic: true` |
| 점검표 | 아파트명 `합성 검수 아파트`, 증상 `방 일부 난방 점검`, 빈 보고서 `null` |
| 다른 기사 점검표 | `403`, `FORBIDDEN`, JSON-RPC `-32003`, path `repair.getById` |

실행 원문은 `review-trpc-client-v37.json`, script source는 `scripts/verify-review-trpc-client.mjs`에 보관한다. 이 범위는 사용자가 이번 요청에서 허용한 합성 검수 계정 전송으로 한정한다.
