# 고객용 지사 현황 공개 정보 read-only 확인

2026-09-15 KST 본사 관리자 세션의 `branch.listAll`을 read-only로 조회했다. 활성 상태인 지사는 한 곳이며, 관리자 등록 `name`은 **퓨처에너지테크 호남지사**다. 요청한 공개 필드 중 대표전화는 등록돼 있으나 주소 값은 **상세 주소 추가 예정**으로, 임의 주소를 고객용 화면에 만들면 안 된다.

| 관리자 등록 필드 | 확인 결과 | 고객용 공개 처리 |
|---|---|---|
| 지사명 | 퓨처에너지테크 호남지사 | 실제 등록명 그대로 사용 가능 |
| 대표전화 | 등록됨 | 전화 문의 연결 가능 |
| 영업주소 | 상세 주소 추가 예정 | 주소·길찾기 미표시 |
| 활성 여부 | 활성 1곳 | 이 1곳만 후보 |
| 전남 표기 | name 필드에는 없음 | region 필드를 별도 확인하거나 사용자 정정 필요 |

다른 비활성 지사는 공개하지 않는다. 본 파일에는 전화번호 원문·관리자 이름·식별자를 기록하지 않았다.
