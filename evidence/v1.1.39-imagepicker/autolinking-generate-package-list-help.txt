Usage: autolinking generate-package-list [options] [searchPaths...]

Options:
  -e, --exclude <exclude...>    Package names to exclude when looking up for
                                modules.
  -p, --platform [platform]     The platform that the resulting modules must
                                support. Available options: "apple", "android"
                                (default: "apple")
  --project-root <projectRoot>  The path to the root of the project. Defaults
                                to current working directory (default:
                                "/home/ubuntu/future-energy-heating")
  -t, --target <path>           Path to the target file, where the package list
                                should be written to.
  -n, --namespace <namespace>   Java package name under which the package list
                                should be placed.
  --empty                       Whether to only generate an empty list. Might
                                be used when the user opts-out of autolinking.
                                (default: false)
  -h, --help                    display help for command
