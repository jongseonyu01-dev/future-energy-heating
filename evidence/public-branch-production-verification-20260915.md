# 고객용 지사 현황 production 검증 기록

검증 일시: 2026-09-15 KST

공식 도메인 `https://xn--h50b270bp0ceuddugnobx2m.kr/branches`에서 로그인 없이 고객용 지사 현황 페이지가 HTTP 화면으로 열리는 것을 확인했다. 화면에는 PC 상단 메뉴의 `지사 현황` 링크가 보이며, 로그인 입력 폼은 없었다.

DOM 검증 결과 공개 카드는 정확히 1개였고, 표시 명칭은 `퓨처에너지테크 호남지사`, 서비스 지역은 `호남권`이었다. `전화 문의` CTA의 href는 `tel:010-3241-5533`으로 확인했다.

공개 화면 본문에서는 `상세 주소 추가 예정`, `길찾기`, `전남지사`, `부천지사`가 확인되지 않았다. 이 확인은 고객 공개 화면 범위에 한정하며, 관리자 원본 지사 데이터·로그인 권한 및 다른 지사 데이터는 조회·변경하지 않았다.

공식 메인 PC 상단에서 `지사 현황` 메뉴를 실제 선택해 `/branches`로 이동하는 것을 확인했으며, 같은 메뉴에 기존 `기사용 앱 다운로드`도 함께 유지되어 있다. 공식 도메인을 390×844 모바일 폭으로 캡처한 화면에서는 햄버거 메뉴와 단일 호남지사 카드, 대표전화 및 `전화 문의` CTA가 모바일 폭에서 가독성 있게 표시된다. 모바일 메뉴의 링크 존재와 대상은 정적 검증으로 확인했고, 운영 화면에서의 실제 메뉴 펼침·선택 동작은 별도 JavaScript 없이 동일한 표준 앵커 링크와 기존 hamburger toggle 방식으로 제공된다.

추가로 390×844 모바일 viewport에서 공식 메인 페이지의 햄버거 메뉴를 실제로 펼쳤다. 메뉴는 `display: block` 상태가 되었고 `📍 지사 현황`의 링크 대상은 `/branches`였으며, 기존 `기사용 앱 다운로드` 링크도 메뉴에 남아 있었다. `지사 현황`을 실제 선택한 뒤 공식 `/branches` 페이지로 이동했고, 페이지 제목·단일 공개 카드·전화 문의 href가 다시 확인되었다. 펼친 메뉴 캡처는 `evidence/screenshots/branch-status-mobile-menu-open-20260915.png`에 저장했다.
