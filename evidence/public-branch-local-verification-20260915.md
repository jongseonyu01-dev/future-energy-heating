# 고객용 지사 현황 로컬 검증 기록

검증 일시: 2026-09-15 KST

운영 홈페이지 작업본의 비로그인 경로 `/branches`를 로컬 HTTP 서버로 열어 확인했다. 페이지 제목은 `지사 현황 | 퓨처에너지테크`이며, 로그인 폼은 없고 관리자 API·tRPC·지사 목록 API를 호출하는 스크립트는 확인되지 않았다.

공개 카드 수는 정확히 1개였고, 카드의 공개 식별자는 `honam`이다. 고객 화면에는 승인된 호남지사 명칭과 서비스 지역 `호남권`, 등록 대표전화만 표시된다. `전화 문의` 링크의 실제 href는 `tel:010-3241-5533`이다.

정적 범위 검증은 PC·모바일 메뉴의 `/branches` 링크, 기존 `/app/driver-download` 링크 보존, 금지 문자열 및 주소 요소 부재를 함께 확인했다. 이 기록은 로컬 작업본 검증이며, 공식 도메인의 production 배포 및 비로그인 화면 확인은 별도 단계로 남아 있다.
