# 운영 EAS production 환경 변수 점검 (값 최소화)

## 목적

운영 APK build에 review 전용 환경 변수가 섞이지 않고 공식 운영 API만 주입되는지 확인했다. 비밀값·소유자 정보·환경 변수 식별자는 기록하지 않는다.

## 결과

| 확인 항목 | 결과 |
|---|---|
| production 환경 변수 목록 조회 | 완료 |
| `EXPO_PUBLIC_API_BASE_URL` | 공식 운영 도메인으로 등록됨 |
| `EXPO_PUBLIC_API_URL` | 공식 운영 도메인으로 등록됨 |
| `EXPO_PUBLIC_REVIEW_MODE` | 등록되지 않음 |
| review preview URL | production 환경에서 발견되지 않음 |
| deployment protection bypass 변수 | production 환경에서 발견되지 않음 |
| 민감 값 원문 | 조회·기록하지 않음 |

따라서 `production-apk` profile은 production 환경의 공식 API base URL을 사용하고, review preview나 bypass secret을 사용하지 않는다.
